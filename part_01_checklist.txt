## 3. UI Components & Inputs
- [ ] Implement required core elements:
  - `View` for structural layout.
  - `Text` for titles, labels, and quantities.
  - `Pressable` / `TouchableOpacity` / `Button` for actions (Add, Delete, Checkout).
- [ ] Implement user input controls:
  - `TextInput` for recipe titles, ingredient names, and quantities.
  - A secondary input component (e.g., `Picker` / `Dropdown` for selecting units like cups, tbsp, cloves, lbs).

## 4. State Management & User Feedback
- [ ] Manage local app state with `useState`:
  - Store recipe lists, selected items, and active input fields.
- [ ] Utilize `useEffect`:
  - Trigger the **ingredient auto-aggregation logic** whenever the selected recipe set changes (e.g., automatically combining `2 cloves garlic` + `3 cloves garlic` $\rightarrow$ `5 cloves garlic`).
- [ ] Provide clear UI feedback on user actions:
  - Show a confirmation banner/toast when a recipe is added.
  - Strike through or highlight items in the cart when tapped/checked off.
